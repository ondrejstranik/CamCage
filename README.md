# CamCage
Progressive web application to control up to two minicameras connected wirelessly.

Link to this app: https://ondrejstranik.github.io/CamCage/

## How to install the PWA locally:

- ### Chrome in Android:
```
👉 Tap ⋮ three dots

- Select Add to Home screen

- Confirm with Add

CamCage now appears as an app icon
```
